## ?? Use Case Examples

### Example 1: Single Friend Spawn

```
User Action:
  Press [

System Flow:
  InputHandler
    ? Detect [
    ? Get SteamFriendsIntegration
    ? SpawnSosigWithFriendName(true)
    ? GetRandomFriendName()
      Returns: "ProGamer99"
    ? AdvancedChatSpawner.SpawningSequence("ProGamer99")
    ? Spawn Sosig
    ? Attach Nameplate: "ProGamer99"

Result:
  ? Ally sosig spawned with friend's name
```

### Example 2: Bulk Friend Spawn

```
User Action:
  Press F7

System Flow:
  InputHandler
    ? Detect F7
    ? Get SteamFriendsIntegration
    ? SpawnAllFriendsAsSosigs(true)
    ? Loop through all friends:
        - "Friend1" ? Spawn Ally
        - "Friend2" ? Spawn Ally
        - "Friend3" ? Spawn Ally
        - ... (all friends)
    ? Attach nameplates to each

Result:
  ? All friends spawned as allies
  ? Each with their own name
```
