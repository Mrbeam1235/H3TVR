# H3TVR Enemy Chat File (Channel Points Compatible)
# SUPPORTED FORMATS:
#   Plain username: ViewerName
#   Key=Value: username=ViewerName
#   Key=Value: user=ViewerName
#   Key=Value: redeemer=ViewerName
# File will be cleared after reading if ClearFileAfterRead is enabled
# Perfect for Twitch Channel Points redemptions!

# Examples of valid formats:
# ViewerName
# username=ViewerName
# user=ViewerName
# redeemer=ViewerName

# Your channel point redemption tool should write one of these formats to this file
# The sosig spawner will automatically detect and spawn for the redeemer!

# Example redemption from Streamer.bot:
# username={user}

# Example redemption from simple script:
# ViewerName

# All of the above will work perfectly!
